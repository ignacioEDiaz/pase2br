# Pase Burger 🍔⚽

Sitio web oficial de **Pase Burger** - ¡Buena Comida, Buen Humor!

Smash burgers artesanales, pan brioche horneado a diario, carne 100% Angus y salsa secreta de la casa.

## Características

- Landing page moderna, responsiva y rápida
- Menú interactivo con filtros por categoría (Smash, Pollo, Papas, Bebidas)
- Carrusel de productos destacados
- Efecto 3D interactivo en tarjetas de menú
- Optimizado para despliegue estático en Vercel
